# 盘屿 0.9.11 兼容测试版 3（构建 91）

独立兼容测试版，不加入正式版应用内更新、官网默认下载或 Homebrew。

## 本次修复

- 针对 Issue #9 报告的挂载路径兼容问题，新普通 NTFS 读写与 BitLocker 解锁改用 `/Volumes` 下各自的隐藏目录；继续识别并恢复旧路径中的会话。
- 保持 root 所有的 0711 父目录、用户所有的 0700 UUID 子目录、磁盘身份与写入安全检查。残留清理只移除已核实未挂载的空目录，不递归删除。
- 兼容新版系统的 `Final mount step ended with error:` 报错格式，使扩展的具体拒绝原因能够正确识别。
- 修复相册导出的照片访问签名权限遗漏，以及读取原片时后台回调引发的线程隔离崩溃。

## 测试范围与反馈

558 项核心测试通过，本地化 767 个键零问题；应用、文件系统扩展与后台组件在本机完成 Apple 芯片 + Intel 双架构构建。该路径兼容改动仍需 Issue #9 报告者在原环境复核，不能由本机结果推断所有 macOS 27.2 的行为。

构建 91 已在 macOS 27.2 实体 USB NTFS 盘完成自动开启读写、新目录写入和 fsync 回读、正常恢复只读、系统重新挂载后的 SHA-256 核验，以及空挂载目录清理。应用和安装包通过苹果公证及装订验证。

相册功能已有一张正常 Live Photo 经实体 NTFS 导出、与系统原片逐字节核对、配对标识验证及只读重挂载复核。另一张样本的配套视频在系统“照片”中也导出失败，因此不计作相册导出通过样本；导出失败时不会用静态图片冒充完整 Live Photo。

保留 beta 1/2 的旧 BitLocker 扩散器和相册原片导出功能。Windows 7 原生 BitLocker 盘、Windows 往返、Live Photo 回导、iCloud 下载及旧系统实机仍需进一步验收。

反馈请注明构建号、macOS、芯片、自动或手动启用读写、实际提示，并附应用导出的诊断；不需要提供个人文件、磁盘密码或恢复密钥。回退可使用独立旧测试版或正式版 0.9.10。
