# 盘屿 0.9.11 兼容测试版 4（构建 92）

独立兼容测试版，不加入正式版应用内更新、官网默认下载或 Homebrew。

- 修正 Issue #9 的后续反馈：普通 NTFS 读写实际挂载到 `/Volumes/卷名`，同名目录追加数字，不再使用隐藏 UUID 目录。
- 挂载目录由后台独占创建，位置与目录身份在挂载前持久保存。继续支持旧隐藏路径会话的识别与恢复；清理仅移除确认归属的空目录。
- 保留磁盘身份、写入安全与后台恢复检查；兼容已恢复原生只读后的重复恢复。

本地核心测试命令通过（摘要 564 项，4 项依赖专用只读镜像的条件集成测试跳过），本地化 767 个键零问题，代码审查未发现问题。应用、扩展和后台组件已在本机完成 Apple 芯片与 Intel 双架构构建。

已用实体 USB NTFS 盘验证自动开启读写、真实 `/Volumes/希捷 2T` 挂载路径、中文文件及 2 MiB 文件写入与 fsync 回读、正常恢复系统只读，以及重挂载后 SHA-256 一致。

升级前请先恢复磁盘只读并退出盘屿，再安装本测试版。原报告者的环境仍需复核；Issue 暂时保持打开。BitLocker 解锁的隐藏目录本次不变；Windows 7 原生 BitLocker、Windows 往返、Live Photo 回导与 iCloud 下载等尚未完成验收。
