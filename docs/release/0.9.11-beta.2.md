# 盘屿 0.9.11 兼容测试版 2（构建 87）

本版本提供独立下载，未加入正式版应用内更新、官网默认下载或 Homebrew。

## 本次新增

在盘屿内选择已开启读写的普通 NTFS 磁盘 → “从相册导出…” → 选择照片或视频 → 选择盘内目标文件夹。

- 导出未修改的原片，Live Photo 自动保留原始图片和配套视频；不包含照片 App 中的后期编辑，不承诺 Finder 将两份文件直接作为 Live Photo 播放。
- Live Photo 任一原片资源缺失、下载失败或准备被取消时，整批不进入拷贝队列。
- 原片准备支持进度、取消与按需 iCloud 下载；准备后接入现有拷贝队列，支持暂停、断盘恢复和写入确认。
- 私有暂存原片在任务确认或取消退休后自动清理；关闭主窗口时后台仍负责清理。

## 测试范围

547 项核心测试通过，新增测试覆盖成对资源、真实文件字节核对、名称冲突、失败和取消、缓存保留、重启恢复、禁止跳过单个 Live 资源及迟到回调。主应用和文件系统扩展在本地完成 Apple 芯片 + Intel 双架构构建，本地化 767 个键零问题。

真实图库首次授权、系统多选界面、iCloud 原片下载、Live Photo 回导及真实外接盘仍待验收；请先使用测试图库中的少量照片和有完整备份的测试盘。首次测试不要只保留导出副本。

## 上一测试版功能

保留 beta 1 的 Windows 7 AES-CBC + Elephant Diffuser 128/256 位 BitLocker 密码/恢复密钥解锁和读写实现。真实 Windows 7 原生磁盘及跨系统双向读写尚待验收，不能据算法测试宣称完整兼容。

反馈请注明版本/构建号、macOS、芯片、所选媒体类型、是否来自 iCloud、失败阶段及提示。请勿提供图库私密文件、磁盘密码或恢复密钥。

回退可重新安装正式版 0.9.10；旧版没有本次相册导出功能，也不能解锁带扩散器的旧 BitLocker 盘。
