# 盘屿 0.9.11 兼容测试版 1（构建 86）

本版本供 Windows 7 旧版 BitLocker 兼容测试，提供独立下载，未加入正式版应用内更新、官网默认下载或 Homebrew。

- 新增 AES-CBC + Elephant Diffuser 128/256 位加密盘的密码及 48 位恢复密钥解锁、读取和写入实现。
- 本地独立算法向量、镜像文件读写、日志恢复及原四种加密方式回归已通过。
- 真实 Windows 7 创建的磁盘、Finder 挂载和跨系统双向读写尚待验收；转换测试镜像未通过 Windows 互操作，不能据此宣称完整兼容。
- 请仅在可丢弃的测试盘或已有完整备份的测试副本上验证；不要用重要数据盘进行首次测试。

测试反馈请包含 macOS 版本、Mac 芯片、加密算法（128/256 位、是否带扩散器）、密码或恢复密钥解锁是否成功、读写及安全推出结果。请勿提供密码、恢复密钥或磁盘私密文件。

回退可重新安装正式版 0.9.10。旧版无法解锁带扩散器的加密盘。
