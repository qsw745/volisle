盘屿 0.9.11 · Volisle 0.9.11

· 新增从相册导出：在磁盘详情中选择照片和视频，直接保存未修改的原片；Live Photo 同时保留图片与配套视频。
· 支持按需下载 iCloud 原片，提供准备进度与取消；导出接入现有拷贝队列，保留写入确认与断盘恢复。
· 新增 Windows 7 旧版 BitLocker 扩散器兼容，支持 AES-128 与 AES-256；已完成实体加密分区的跨系统双向读写验证。
· 修复启用 NTFS 读写后部分软件无法找到磁盘路径的问题，恢复使用正常的卷名路径。
· 兼容范围以官网说明为准；建议先用少量有备份的数据验证自己的磁盘与图库。
· Export selected photos and videos from the disk detail page as unmodified originals. Live Photos retain both their image and paired video.
· Download iCloud originals on demand, with preparation progress and cancellation, then use the existing copy queue with write confirmation and reconnect recovery.
· Add compatibility with Windows 7 BitLocker AES-128 and AES-256 Elephant Diffuser encryption, validated with physical encrypted partitions and bidirectional Windows/Mac file checks.
· Fix disk paths becoming unavailable to some applications after enabling NTFS write access by restoring normal volume-name paths.
· See the website for compatibility limits. Try a small set of backed-up data with your own disk and library first.
