## 官网分发计划

1. 沿用已注册的 `top.qisw.volisle`、`top.qisw.volisle.filesystem` 和已核对的开发团队；品牌采用盘屿 Volisle 及已选 Logo。正式域名与支持渠道仍须确定，不能用示例地址替代。注册证据见 `签名账户核对.md`。
2. GPL 组合与对应源码审查通过，记录源代码提供/修改声明或商业许可依据。
3. 原生 App 与实际扩展/辅助服务分别使用正确 entitlement、Developer ID 签名和 Hardened Runtime。
4. 从最终包逐项检查签名、嵌入组件、架构与权限；提交 Apple 公证，装订凭证，在干净系统验证安装与卸载。
5. 独立决定 DMG/PKG；有需系统安装的组件才选 PKG。不可仅把开发 .app 压缩后叫正式安装包。
6. 更新采用签名验证和 HTTPS；Sparkle 等机制需另行审查、锁版和测试，当前未接入。
7. 通过最终磁盘闭环、Windows 检查、异常矩阵后建立真实发布记录，官网才开放下载链接及版本/系统要求。
8. 公开托管前设置真实域名、canonical、sitemap.xml、索引策略、缓存和自定义 404。本地预览 `noindex` + robots 禁止抓取；保留 HTML 站点地图，不伪造域名。

## 卸载

普通未安装的构建目录与已注册的签名测试应用须区分。后者包含系统已启用的 FSKit 扩展，不能仅凭主窗口退出就认定可以安全删除。正式卸载流程仍待开发和验收：检测所有使用中卷、等待写入刷新、非强制卸载；任何繁忙或失败都阻止移除引擎，并提示稍后重试。不得直接删除正在使用的扩展。只清理盘屿自己的文件，不能顺手移除用户安装的其他 NTFS 软件。

## Mac App Store

单独评估应用沙盒、FSKit 权限、引擎许可、扩展嵌入方式、辅助服务限制及审核政策。框架可以商店分发与整个产品能通过审核是不同结论。当前未创建商店记录、未提交构建。
