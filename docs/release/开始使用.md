# 开始使用盘屿

1. 把“盘屿”拖到“应用程序”文件夹，然后打开它。
2. 第一次打开会弹出设置向导，按提示完成三步：允许盘屿在后台运行、启用盘屿的文件系统扩展、允许盘屿读取磁盘。每步点按钮会直接打开对应的系统设置页面，打开开关后向导自动打勾。中途关掉也可以在“设置 → 首次使用”中继续。
3. 插入 NTFS 移动硬盘或 U 盘。盘屿检查通过后自动开启读写，之后在 Finder 和其他应用里照常使用。
4. 用完在盘屿或 Finder 中推出，再拔线。

磁盘保持只读时，看窗口底部的提示按步骤处理。帮助与兼容性说明：https://qisw.top/volisle/help/
