# ADR-001：用户态优先，未验证能力默认关闭

状态：研发基线；2026-09-20 改为免费开源优先，直接 FSKit＋开源 NTFS 核心为优先验证方向，后续评估 Mac App Store 收费。商业 SDK 询价已暂停。以 `docs/product/开源与商业化规划.md` 为当前路线。

选择引擎可替换架构。UI 只接受结构化磁盘和能力模型；当前产品适配器 ReadOnlyFSKitEngine 查询真实扩展状态，但明确拒绝写入。GPL 桥接已嵌入已签名测试应用，完成隔离镜像的系统读写与部分中断检查；真实盘产品写入适配器仍未完成。macFUSE 仍仅为调研候选。

不采用自行实现完整 NTFS、不替换系统 mount_ntfs、不借助现有消费版 Tuxera 授权来冒称自有能力，不降低 SIP 或启动安全策略。macFUSE 如进入实验，必须显式选择并核实用户态后端。

界面分别显示挂载状态与盘屿引擎能力。风险未知不自动转为安全，容量未知不转为零，不能用变化的 BSD 编号持久识别卷。挂载协调 actor 按物理设备互斥，调用引擎前重读身份；真正适配器还必须在持有设备句柄后完成身份与安全检查。发现服务提供实时 VolumeResolver；手动写入 UI 已连接控制器与协调器，但当前只读适配器不授予写入能力。

后果：可以独立交付只读客户端和官网，在读写闭环通过前不开放自动挂载或 NTFS 写入。正常系统卸载/推出已独立实现，实盘验收另行记录。SMAppService/XPC 只在实测证明需要提升权限后设计，不提前植入通用 root 服务。

2026-09-21 状态核对：实际 Bundle ID/Team、Developer ID 测试候选签名、系统扩展加载及部分镜像验收已有 2026-09-20 记录，无需重复注册。待完成真正的写入适配器、完整权限与故障验收、公证及发布工程、开源组合的分发核验和支持版本下限确认。商业 SDK 合同不属于当前路线的前置条件。已签名测试候选包含实际 Bundle ID，但仍不能作为正式分发包。

2026-09-20 实施补充：挂载协调先通过 `WritePolicy.validateTarget` 核对身份和保护范围；发现服务的未知风险只允许进入引擎检查，不允许直接写入。引擎返回 clean 后重读目标并再次核对身份与新风险，再交给适配器执行最终设备句柄检查。引擎返回 unknown/risk 均拒绝挂载。界面引擎状态、系统挂载状态与卷安全状态分别表示，不互相推导。
