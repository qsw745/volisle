# 官网版 0.9.8（80）验收

## 改动

- GitHub #6：菜单栏与 Dock 显示开关独立，默认开启，通过 AppStorage 保存。
- Dock 关闭时采用 AppKit accessory 策略，开启恢复 regular；重新打开现有主窗口时显式置前。
- 设置说明隐藏后的重新打开入口以及 Dock 隐藏时不出现在 ⌘Tab 的行为。
- 未包含主工作区现有商店版或扩展改动。

## 本地验证

- 501 项核心测试通过；741 个本地化键无问题。
- arm64 和 x86_64 构建、签名与已安装载荷一致；扩展声明、三组件签名权限及后台启动配置与 0.9.7 一致。
- 设置界面默认开启；Dock 关闭后运行进程策略为 accessory（1），开启后为 regular（0）。
- 两图标设置均关闭后执行关闭窗口，再次打开 /Applications/Volisle.app 可进入主窗口，PID 未变，后台组件保持连接，现有磁盘显示可读写。
- 正常退出后进程消失；重启应用后两个开关仍为 off，策略仍为 accessory。完成后恢复两个开关为 on。
- 一次性镜像写入、fsync、改名、独立 NTFS 读取和只读重新挂载通过；镜像卸载完成。未对用户磁盘执行测试写入。
