# 可信日志池与统一预算验收

日期：2026-09-25。

## 改动

此前批次压缩检查依赖调用者传入日志目录。测试复现：真实目录还有已完成日志时，传入另一个空目录仍能清空凭据。当前严格入口把唯一日志池纳入认证状态，错误目录不能再作为“全部日志已回收”的依据。

- 认证状态格式 5 保存日志池的绝对路径、文件系统 UUID、目录 inode、创建时间，以及容量/文件数预算；每次打开和业务操作都核对。文件系统 UUID 通过持有的目录描述符读取，不用易随挂载变化的设备编号作为持久身份。
- 系统入口固定为 `/private/var/db/volisle/block-logs`，目录由 root 私有管理，默认统一 1 GiB / 256 文件；本轮没有在本机调用该系统入口或创建这些目录。
- `beginTransaction` 统一选择目录、密钥、预算和凭据保存回调。不同卷不会各自获得一份额外预算；整个事务持有池锁，当前模型串行使用池。
- 日志读取、对账、恢复、完成、回收、批次切换和中断发布均可核对实际打开的目录身份。严格可信入口必须匹配配置，日志层同时检查持有描述符与当前路径，拒绝符号链接、重命名、替换和权限变化。
- 初始化必须在空池独占锁内生成密钥及初始状态。有旧日志、未知文件或锁冲突时，不生成新密钥去接管它们。
- 新入口拒绝无池绑定的旧凭据，不自动迁移、不换密钥。旧格式专项仍由仅测试编译开放的旧夹具运行；生产构造入口始终要求池配置。格式 5 不能被旧格式代码误读。
- 目录身份、路径或预算发生改变时停止处理。没有加入自动搬迁、自动放宽预算或自动重新绑定。

补充测试发现日志刷盘期间替换池目录时，单独日志层仍会返回新凭据；已将池核对并入刷盘前后的文件核对，修复后该情形拒绝返回成功。事务协调器原有的凭据核对继续保留。

预算是日志逻辑额度准入，不是磁盘物理预分配，不保证磁盘永远不会满。本轮使用单一池统一预算，不实现多个历史目录的自动发现/合并。若未来需要迁移目录，必须另做显式迁移协议。

## 未完成边界

这完成了日志池配置和预算约束组件，未完成正式后台接入。生产独立检查点、真实设备身份/独占访问、后台自动回收/切换调度及 FSKit 持续挂载仍待实现和验收。真实断电、跨系统、长期负载也未由这些镜像用例覆盖。

目录身份校验不声称防御 root 克隆/回滚整个文件系统及密钥；本轮验证包括同一系统内进程重启，没有执行操作系统重启或跨盘迁移。原生日志组件尚未用于安装版，发布阻断维持，未替换应用、调整权限、部署网站或发布更新。
