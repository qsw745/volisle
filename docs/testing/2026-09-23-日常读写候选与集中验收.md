# 0.2.0 日常读写候选与集中验收

本轮交付可安装的日常读写候选；原始“完整正式产品”目标仍未全部达成。不能仅凭本机测试将本候选视为已经完成正式发布。

## 开发和真实结果

- 显式 `--daily-write` 构建/签名模式，不再绑定两小时有效期、单一测试目录或固定 disk 编号。默认构建仍只读。签名时独立核对模式与资源，拒绝与镜像/实盘限时实验混用。
- 日常后台只接受重新核验的外接 USB 分区；应用签名、调用者 UID、IORegistry 身份、容量、NTFS 引导及模块内休眠/dirty/日志检查保留。不提供任意命令或路径接口。
- 主界面和菜单栏接到同一持久事务；打开 Finder 前复核真实挂载，推出先正常结束写入；忙碌则保留恢复状态，不强制。
- 自动挂载偏好接到同一后台入口，默认关闭，重复连接回调不会反复写入。只有稳定身份可用的卷可启用；当前 qsw 缺少系统卷 UUID，因此该盘自动读写禁用。
- 后台恢复状态机新增原连接消失证明，旧启动/拔盘场景不对复用 BSD 名称的新设备发起恢复。自动化覆盖此行为；本轮未实际拔线或重启系统。
- 修复无 UUID 的 MBR 卷不能正常推出、恢复成功仍显示旧恢复错误、等待人工恢复时错误显示持续忙碌、推出成功被旧恢复提示覆盖。
- 设置增加首次授权引导，保留完全磁盘访问；安装更新脚本保留每个旧包、先停止空闲后台、拒绝在有挂载或未结束事务时替换应用。

## 正式产品仍缺

1. 同名替换保存、私有 POSIX 权限，完整的文件/目录语义及崩溃可靠性。现有小镜像替换实验不能直接当作生产实现开放。
2. 丢失启动回复且服务没有对应记录时的安全收尾协议，当前保持阻止；后台进程实际崩溃、物理热拔插、休眠与磁盘满完整矩阵仍需验收。
3. Windows 交叉检查、多系统/Intel 兼容、完整语言与辅助功能验收。
4. 公证、干净机器安装/卸载验收、自动更新、真实官网域名/运营信息、公开源码托管及 App Store 独立分发审核。
