# 商店版 1.0.1（10）改进、验收与重新送审

日期：2026-10-24，北京时间。用户选择“1.0.1：纳入安全改进，不含内购”并授权打包后重新审核。本文件的最终审核状态以文末 API 回执为准。

## 实际改动

从已送审的 `store-1.0-build9` 隔离开发，保留 Finder 直接读写、FSKit 沙盒、26.4 最低系统和原有 NTFS/写入日志实现。没有纳入 1.1 内购、高级设置、睡眠保护或菜单栏功能，没有尝试修复 macOS 15 兼容性。

- 扩展把失败状态与本次激活 UUID、固定激活时间一起传给主应用。
- 首写、检查点或结束会话失败后发布停止状态；主窗口与侧栏显示“写入已停止”及核对建议，撤去正常写入说明。
- 同次挂载的已知失败保守保持；旧挂载迟到消息不覆盖新挂载。对挂载卷每 4 秒复核状态，补偿通知与偏好记录到达次序差异。
- 简繁英同步新增三条安全文案。
- 仅限本地商店候选的故障钩子，用于真实 FSKit 失败路径验收。正式商店包在环境、配置和构建回执三处拒绝测试标记；公共构建脚本拒绝在非商店模式启用该钩子。

这是故障可见性的实质改进，不保证消除 4.3 / 4.2.6 的产品差异化疑虑。审核说明如实保留第三方来源、内部测试范围及无外部 beta 用户反馈的事实。

仅新建 128 MiB NTFS 镜像 `VOLISLE-101`，确认实际运行的扩展来自本次 `/Applications/Volisle MAS Probe.app`，并核对挂载类型 `volislemas`。

1. 4 MiB 文件写入回读 SHA-256 一致、20 个中文名小文件、改名、删除及扩展属性通过；正常分离重挂后结果一致。
2. 本地故障候选触发检查点失败，实际虚拟属性报告 `stopped`；应用侧栏和详情出现停止告警，原先正常写入说明消失。已持久化的基线文件摘要未变。
3. **该次故障后普通推出/卸载被拒绝，不记为正常推出成功。** 核对只有该一次性镜像被 Volisle 挂载后，仅结束精确测试扩展进程，随后未使用 force 的分离成功。重挂后基线和 20 个文件一致，新写入通过，UI 的旧停止告警清除。
4. 默认只读重挂实际返回 `read-only`，创建文件返回 EROFS；镜像正常分离，原偏好恢复。
5. 无故障宏的本地生产模式候选再次验证：特殊触发名是普通文件，正常写入、追加、推出和重挂持久性通过。

故障钩子和受控进程退出只是测试方法，既不随正式包分发，也不是建议用户对真实磁盘采取的恢复步骤。不能据此承诺所有设备故障后均能正常推出或零丢失。

独立审查检查锁顺序、发布队列顺序、首写/关闭失败检测、状态锁存和轮询绑定。发现非商店故障标志继承风险后已修正，并由门禁变异测试覆盖；没有其他已证实的重要问题。
