新增可复用工具 `scripts/test-update-failures.py` 及 `scripts/fixtures/update-failure`。使用本机编译的 Sparkle 2.10.0、临时测试密钥、一次性应用身份和回环 HTTP；生产私钥、当前安装应用、后台服务和磁盘均不参与。

| 故障 | Sparkle 错误码 | 结果 |
| --- | --- | --- |
| 更新目录 HTTP 503 | 2001 | 检查失败，保留原应用 |
| 未签名更新目录 | 1000 | 拒绝目录，未下载包 |
| 签名后修改目录 | 1000 | 拒绝目录，未下载包 |
| 归档传输中断且长度不足 | 2001 | 下载失败，保留原应用 |
| 归档 Ed25519 签名错误 | 4005 | 验签失败，未进入安装 |
| 签名正确但内容不是 ZIP | 3000 | 解压失败，未进入安装 |
