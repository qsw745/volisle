# 0.3.0 → 0.3.1 应用内自动更新验收

日期：2026-09-27。环境：Parallels macOS 26.6（25G72）虚拟机，Apple 芯片，Gatekeeper 开启。更新源为线上正式目录 https://qisw.top/volisle/updates/appcast.xml 。

## 起点

- 用户在虚拟机中用 Safari 下载官网 `Volisle-0.3.0-arm64.dmg`，在 Finder 中拖入“应用程序”（替换旧副本），从“应用程序”打开并完成首次设置（允许后台、启用扩展）。
- 应用从 `/Applications` 直接运行，未被转移隔离；隔离标记 `01c3`（含 Finder 拖拽安装的 0x100 标志）。
- 应用、后台组件、扩展三个可执行文件与 `dist/Volisle-0.3.0-build14` 发行包逐字节一致；后台组件运行中。

此前虚拟机中的另一份 0.3.0 被系统转移隔离（隔离标记 `00c3`，缺少 0x100 标志），说明它不是从 DMG 经 Finder 拖入的；按正常流程重装后不再出现。转移隔离不是普通安装流程的问题。

## 过程

本轮没有桌面控制工具，未通过“检查更新…”窗口操作，改走 Sparkle 的“自动下载、退出时安装”路径。该路径与“安装并重新启动”使用同一安装器和同一保护门禁。

1. 正常退出盘屿；把 `SUAutomaticallyUpdate` 设为开启、`SULastCheckTime` 调早；重新打开。
2. 启动后 10 秒内完成检查、下载和解压。下载的 ZIP 为 3,246,433 字节，SHA-256 `3b9f2870…d773`，与线上文件一致；解压出的主程序与 0.3.1 发行包一致。Sparkle 安装进程就位等待退出。
3. 21:43:03 正常退出，约 1 秒后 `/Applications/Volisle.app` 变为构建 17，安装进程结束。
4. 安装后后台组件已停止并注销（保护门禁行为）；重新打开后自动重新注册并运行，没有出现新的授权提示。
5. 测试完成后把 `SUAutomaticallyUpdate` 恢复为关闭。
