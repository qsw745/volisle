## 改动

- 新增 `PhysicalWritePolicy`：签名绑定 UID、单个分区、IOMedia 注册 ID、容量、系统启动会话、引导摘要、固定测试选项、专用目录及有效期。
- 后台只接受外置 USB 分区；原始设备读取权限不满足时，在卸载前拒绝。写入激活前核对实际引导摘要；扩展保留原有脏卷/休眠预检和测试目录限制。
- 测试范围到期后禁止新写入激活，但允许同一设备、同一启动会话下的只读恢复。恢复前重新核对身份，重新挂载时核对引导摘要。
- 构建与签名新增 `--write-service-physical`，必须同时使用有效的 `--physical-test`，不能混用镜像授权。签名时重新捕获注册 ID 和启动会话，设备重新连接即拒绝旧候选。普通构建不嵌入写入授权资源。
- 界面仅为匹配签名范围的选中卷显示“启用测试读写”。提交前持久保存写入用途，使用已接通的后台 `.startWrite`；超时不能被当作未执行，也不能改发只读操作。
- 可写完成必须同时核对后台记录与实际挂载设备、路径、类型及权限标志。使用同一个“恢复只读”入口；打开 Finder 前再次核对挂载。
- 后台持有可写事务时继续阻止其他挂载/卸载操作；已验证的当前卷可以打开 Finder。普通版本的自动挂载能力未开放。
