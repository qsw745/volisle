2026-09-23，本地 macOS 27.2 / Apple Silicon。此增量扩展隔离验收容量，不向日常版开放同名替换。

## 改动

一次性镜像新增 512 MiB，默认仍为 64 MiB。准备、校验、构建、签名和 FSKit 激活沿用镜像哈希及序列号绑定，并把精确容量写入实验构建。只允许这两种容量；128 MiB 和实体 2 TB 不能因这次修改获得覆盖实验权限。读写前置检查仍会拒绝休眠等风险。

C 桥接在实验编译开关内接受 512 MiB；普通编译的替换操作继续拒绝。后台镜像事务仍仅支持 64 MiB，构建及签名入口对 512 MiB 后台组合明确报错，避免生成无法工作的策略。没有扩大后台磁盘权限。
