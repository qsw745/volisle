# 私有权限与应用保存验收（2026-09-24）

用户已确认方案 A：保留 Windows 权限，以盘屿独立记录提供 Mac 挂载期间的访问模式。该选择不是加密，也不代表跨系统身份映射。

## 已完成的实现

- 增加 `$VOLISLE.MODE` 32 字节记录，绑定 MFT 引用及序列号，包含版本、节点类型、模式、保留值与完整性校验；模式不依赖文件路径。
- 普通文件支持 0400/0600/0444/0644，目录支持 0700/0755。默认构建也读取已存在的模式；没有记录沿用历史共享模式，存在但无效则 EIO 并锁定后续写入。
- 新建节点先持久化 0000 中间状态，再持久化最终模式，完成后才向 FSKit 返回成功。故障会保留脏标记。公开接口不允许用户直接设置中间状态。
- 普通扩展属性不能读取、覆盖、删除权限流，枚举隐藏该流；非法记录在属性读取、内容读取、目录/扩展属性入口拒绝。
- 旧的 READONLY 单位接口遇到持久 Mac 权限记录明确拒绝，不会 chmod 返回成功但模式没有改变。
- `--experimental-private-permissions` 与替换开关分别门控，必须绑定新镜像，不能和日常、实盘或后台实盘构建混合。日常版继续关闭权限写入和同名替换。
