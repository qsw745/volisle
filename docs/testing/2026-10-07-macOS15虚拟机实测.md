# macOS 15 虚拟机实测

日期：2026-10-07。结论：macOS 15.6.1 虚拟机的主要磁盘流程通过；默认构建目标降为 15.4。15.4 本身未运行实测，不能把最低编译目标当作该版本的实测结果。兼容候选版为 0.8.2（构建 68），只在虚拟机安装，尚未公证或发布。官网公开包仍为 0.8.0 / 66、最低 26.4，历史包与签名更新目录不变。

## 环境与安全边界

- 主机 macOS 27.2；客户机 macOS 15.6.1（24G90）、Apple 芯片，使用 `tools/macos-vm` 的 Virtualization 启动器。虚拟机保持运行，没有改换 Parallels。
- DHCP 地址不可用后改用 IPv6 链路本地 SSH（`~/VolisleVM/vmssh`）；不需要关闭 Shadowrocket 隧道。旧记录中“必须关闭隧道才能继续”的结论已由实际直连纠正。
- 测试版为日常读写构建、既有 Developer ID 签名，客户机路径 `/Applications/Volisle.app`。后台组件卸载注册后重新安装；读回为 `connected`、`packageVerified=true`。沿用客户机此前已批准的权限。
- 普通 NTFS 使用原 GPT 8 GiB、MBR 4 GiB 映像的独立克隆，通过虚拟 USB 控制器热插拔。BitLocker 使用 Windows 生成的四种夹具的独立派生 USB 映像。没有写入或抹掉主机真实 qsw 硬盘，也没有改写原夹具。
- 安装前正常结束挂载、退出旧 App/扩展/helper；旧 App 保留在客户机 `~/VolisleRollback/*.rollback`。本轮未替换主机 `/Applications/Volisle.app`。

## 问题与修复

1. **扩展检测**（Claude 提交 `5ad4c5b`）：15 的 `FSClient.fetchInstalledExtensions` 不列出本应用模块；26 以下改用 pluginkit 登记与 mount 探测。原客户机开关实验确认关闭与启用可区分。
2. **普通写入挂载**（Claude 提交 `27e0ab7`，本轮补强）：15 的 mount 以 root 运行时不依赖 `SUDO_UID` 找到用户启用的模块。26 以下以登录用户执行 mount，仅在 mount 子进程期间临时借出块/字符设备节点。归还后重新核对 UID/GID/mode；归还失败不报告成功。校验 inode/rdev/type，避免同名新设备被错误归还。仍要求唯一且精确的设备、路径、文件系统类型，拒绝内核只读；仅放宽旧 FSKit 不反映的 `nosuid/nodev` 标志。
3. **BitLocker 挂载**：同样采用旧系统用户身份与临时设备借出。macOS 15 不可靠地反映扩展只读状态，所以新增只读虚拟根属性 `top.qisw.volisle.mount-mode`，由扩展报告 `read-only/read-write/stopped`，设置或删除均拒绝。helper 在旧系统必须读到可信模式才成功；App 对缺失、损坏、停止或失败残留挂载保持不可写。失败时只正常卸载本次精确挂载；helper 在挂载前建立根目录下的 root 所有 pending 标记，仅在权限归还、身份、挂载与模式全部核验成功后删除。失败残留或未完成挂载在 App/helper 重启后仍不可写，标记不含密钥。
4. **界面响应**：旧系统挂载模式查询移到后台，核验完成前禁止写入，避免磁盘卡顿或断开时同步属性查询阻塞主界面。每个控制器仅允许一项查询运行，挂载变化会废弃旧结果，不会反复累积无法取消的同步查询。

## 覆盖范围与交付

- 自动读写与续传由真实 App 执行；BitLocker 和抹掉经正式已安装 helper 接口；恢复导出经正式协调器。虚拟机窗口可观察，但当前界面控制工具无法向该窗口可靠注入点击，因此没有逐个点击 GUI 的“拷入、恢复、抹掉”按钮；界面标签与按钮的完整交互验收仍未覆盖。
- 15.4 实机、macOS 15 的实体 USB、睡眠唤醒、Windows 往返、加密盘写入中热拔与全新系统权限重走未在本轮覆盖。虚拟 USB 热拔验证了设备消失路径，不等同真实硬盘断电缓存行为。
- 默认最低目标已在扩展、格式化引擎、mkntfs、候选包与签名构建记录检查中统一为 15.4，保留 `VOLISLE_MIN_MACOS` 显式覆盖。核心包与 App 的 SwiftPM 平台原已为 15.4。
- 官网源码中加入候选版的 15.4 目标和 15.6.1 实测范围；当前下载版仍明确要求 26.4，避免旧 DMG 的系统要求与文案矛盾。没有部署官网，没有修改历史 appcast，没有生成新正式发行包。
- 最终本机构建、签名、安装读回与回归结果见下方收尾核验；本轮代码与文档未提交或推送。
