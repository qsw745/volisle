# 0.3.2 显示名与 0.3.1 → 0.3.2 自动更新验收

日期：2026-09-27。

## 按语言解析（构建 18 签名候选，复制为 `Volisle.app`）

用 `Bundle.preferredLocalizations(from:forPreferences:)` 按指定语言解析包内 `InfoPlist.strings`：

| 系统语言 | 应用 | 文件系统扩展 |
|---|---|---|
| zh-Hans-CN | 盘屿 | 盘屿 NTFS |
| zh-Hant-TW、zh-HK | 盘屿 | 盘屿 NTFS |
| en-US、en-GB | Volisle | Volisle NTFS |
| ja-JP、fr-FR（无对应本地化，回落开发区域 en） | Volisle | Volisle NTFS |

说明：不带本地化的命令行程序读取其他包时只会得到开发区域（en），因此不能用它直接判断 Finder 显示；以上为按语言的解析结果。

## 实机

- 宿主机（中文，macOS 27.2）：本机测试版构建 18 的菜单栏应用名由“Volisle”变为“盘屿”。测试版包名为 `Volisle Test.app`，与基础名不一致，Finder 按设计仍显示文件名。
- macOS 26.6 虚拟机（中文，Gatekeeper 开启）：0.3.1 → 0.3.2 经线上更新目录自动下载、退出时安装，构建 18，主程序哈希与发行包一致，Notarized Developer ID，后台组件自动恢复运行，无转移隔离。更新后 `kMDItemDisplayName` 与 LaunchServices 显示名均为“盘屿”，Finder“应用程序”中显示为“盘屿”（截图 `screenshots/2026-09-27-0.3.2-中文系统显示名.png`）。

## 未覆盖

- 英文系统的实机显示：未改动虚拟机系统语言，仅有上面的按语言解析结果。
- 系统设置“文件系统扩展”列表中的扩展名称实际显示。
- 扩展 `FSPersonalities` 中的格式名仍为“盘屿 NTFS”，未做本地化（Finder 简介中的格式名在英文系统上可能仍显示中文）。
- 应用界面文字仍只有中文。
