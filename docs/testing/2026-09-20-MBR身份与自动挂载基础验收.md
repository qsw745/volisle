# MBR 身份与自动挂载基础验收

日期：2026-09-20。用户已指定 2 TB Windows NTFS 外接盘，可在独立新建目录进行正常读写测试；本轮仍只有只读系统元数据查询，未写入、卸载或加载驱动。

## 完成内容

- MBR 兼容：不再要求所有磁盘都具有 GPT 媒体 UUID。优先使用媒体 UUID；MBR 使用卷 UUID，以及 USB 序列号、USB 厂商/产品编号、分区起点和长度的版本化 SHA-256 摘要作为持久偏好键。USB 端口、BSD 编号和连接令牌不进入持久偏好键，原始序列号不落盘。缺失或明显占位序列号时不生成摘要；枚举在设备节点停止，不使用上游 USB 集线器序列号。
- 当前操作与持久偏好分开：卷 UUID、设备关系和本次 IOMedia 实例可用于当前操作校验；缺少可持久身份时不保存自动挂载偏好。连接令牌仍参与当前身份比较，旧快照不能授权重插后的新对象。
- 系统卸载/推出在获取 DADisk 后再次比较 IOMedia 实例及摘要，避免 BSD 编号在重新解析后被复用。此检查是元数据检查，不产生卸载调用。
- 自动挂载偏好默认关闭，按卷保存在本地。损坏或未来版本的偏好文件按关闭处理。只接收明确 NTFS 文件系统类型，避免通过字符串包含匹配误认其他文件系统。
- 自动挂载控制器已接入客户端磁盘发现更新；仅显式开启的卷可进入流程。引擎能力、物理设备互斥、身份与真实风险检查仍由挂载协调器执行。重复身份、未知挂载状态、已可写、受保护卷均跳过；失败每次连接只尝试一次。检查中关闭偏好、拔盘或出现重复身份会取消尚未完成的请求；协调器在写挂载前再次检查取消、身份和挂载状态。
- 界面保持原布局。按卷开关收在“更多”中，仅当盘屿自身引擎具备真实读写能力时显示。当前仍使用 UnavailableEngine，因此没有新增可点击的写入或自动挂载控件。

摘要身份是设备匹配证据，不是密码学设备认证。序列号重复、克隆卷、设备桥接芯片不提供可靠标识时仍需拒绝不明确的自动操作。真正写入的适配器还必须持有资源后重验身份，正常卸载系统只读挂载并确认没有其他驱动占用；该适配器尚未完成。
