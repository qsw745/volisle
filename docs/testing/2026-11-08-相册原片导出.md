# 相册原片导出本地验证

日期：2026-11-08。分支：`codex/photos-live-export`。基于已发布的 BitLocker 兼容测试版进行开发；本功能未发布、未修改已公开安装包或稳定更新渠道。

## 用户入口与行为

在盘屿选择已开启读写的普通 NTFS 磁盘，在详情页点“从相册导出…”，授权读取照片，选择照片或视频，再选择盘内目标文件夹。准备原片后进入现有拷贝队列。准备阶段可取消，队列阶段支持暂停、取消、断盘恢复与持久写入确认。

一次导出生成独立批次目录，每个所选项目各有子目录。普通照片保留原始图片（含 RAW+JPEG 资源），视频保留原始视频，Live Photo 保留原始图片与配套视频的字节和内部关联元数据。二者任何一份缺失或下载失败则整批不入队。此功能导出未修改的原片，不包含照片 App 的后期编辑，也不承诺 Finder 将图片加视频直接作为 Live Photo 播放。

源图库不会被修改。不增加分享扩展；后台 helper 与文件系统扩展没有新增图库权限。入口限定盘屿普通 NTFS 写会话，未扩展到当前独立的 BitLocker 解锁界面。

## 待真实场景验收

自动化只读写临时目录，没有读取用户个人图库或插拔物理磁盘；以下不算已通过：

1. 使用含 Live Photo、普通照片、RAW+JPEG、普通视频的测试图库，验证首次允许、拒绝后重新授权、取消系统选择器以及多选导出。
2. 对 iCloud 未下载原片验证联网下载、断网失败、准备期间取消及本机空间不足。
3. 在测试 NTFS 盘导出，核对每个 Live 子目录均含图片和视频，可重新导入照片 App 验证配对；比对源资源与目的文件 SHA-256。不要以单独静态图片预览是否会动作为配对验收。
4. 拷贝中拔线后重连，确认任务继续且不会跳过配套资源；退出重启同样检查。确认写入完成前，暂存资源必须存在；确认或取消退休后应清理。
5. 导出入队后关闭主窗口，让后台完成确认，检查暂存自动清理；需要继续核验最低 macOS 15.4 与真实 Intel 设备。

图库授权、系统选择器、iCloud 及真实 Live 回导需要在授权的测试图库和测试盘上执行，不能由编译或模拟资源测试替代。
