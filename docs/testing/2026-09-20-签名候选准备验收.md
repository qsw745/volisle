## 产物与验证

候选路径：`apps/macos/build/review-verified/top.qisw.volisle.app`。保留之前 `build/review` 产物，新候选使用单独目录，不覆盖。

主应用 release 构建和 FSKit 扩展编译通过。主应用与扩展均为 arm64；两份 Info.plist 的应用标识与配置一致，最低系统为当前实验目标 macOS 26.4。扩展不自动认领 NTFS、不启用内核卸载 I/O，构建未开启实验写入宏。构建日志：`.workbench/prepare-verified-bundle.log`。

构建摘要绑定扩展二进制 SHA-256；打包后记录 14 个文件的哈希与权限。签名前和复制后均需匹配记录。构建记录只检测本地旧产物及意外改动，不替代正式签名、公证或真实加载测试。
