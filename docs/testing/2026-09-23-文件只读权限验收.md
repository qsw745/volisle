# 文件只读权限验收

2026-09-23，本地候选增量；尚未完成完整正式产品。

## 已实现

普通文件的 `0444 / 0644` 对应 NTFS 标准 Windows READONLY 位。读取属性时返回实际模式；创建/设置文件属性通过桥接持久化。只读文件的路径写入、MFT 引用写入及截断均返回 EACCES；权限拒绝不会被当成 I/O 故障污染写入会话。真正的元数据写入失败会封锁会话，卸载不能把失败卷标成干净。

修改仅涉及 READONLY、变更时间及相关文件名元数据。Windows 所有者、安全描述符和其他属性位保持原样。目录维持原有 0755 模式，私有权限、执行权限、特殊权限位和用户/组修改仍拒绝，不返回虚假成功。

混合属性请求全部预校验后才开始修改；显式解除只读先于截断，设为只读后于其他请求。FSKit 消费位只标记已经成功的字段。没有新增复杂界面或权限管理页。

## 仍未覆盖

只读位不是保密功能，也不替代 Windows ACL 或用户身份映射。0600 私有权限仍未支持；同名替换仍仅在隔离实验构建开放，尚未完成实际应用保存兼容。Windows 实机、多系统、实体热拔插/断电、公证和公开发布仍待完成。本轮没有对 qsw 实体盘执行挂载、读写、格式化或文件修改。

权限策略参考上游官方说明：[NTFS-3G 文件所有权和权限](https://github.com/tuxera/ntfs-3g/wiki/File-Ownership-and-Permissions)。
