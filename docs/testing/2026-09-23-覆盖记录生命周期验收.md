# 覆盖记录生命周期验收

本轮解决两个长期使用问题：活动恢复记录达到 512 事件后失败、累计 256 个记录目录后无法激活。覆盖功能仍只启用于绑定 64 MiB 镜像的实验构建，未在日常候选或 2 TB qsw 上开放。本轮没有操作 qsw 的文件，也没有格式化或更改完全磁盘访问。

## 实现及安全边界

`ReplacementJournal.swift` 增加有界检查点：在稳定的 published 状态、下一次写入意图之前，累计约 128 条事件时写入 version 2 检查点。新文件写入并同步、原子替换检查点、同步目录之后，才删除被覆盖的旧事件；删除完成再次同步目录。正常活动目录不超过 130 个记录文件，事件序号继续递增。旧 version 1 的完整事件链仍可读取。

检查点保存卷身份、源/目标身份、内容指纹和回收状态。读回验证封装摘要、字段、连续事件及文件所有权/权限/类型。未提交的临时文件、损坏检查点、缺失后续事件和未知文件会使整份检查无效；有效前缀只用于诊断。重放始终没有删除旧文件的授权，不能恢复成可写会话。

完成日志先验证完整 cleaned 状态，再在同一私有宿主目录中移动至 `.completed`；跨卷保留最近 64 份完成日志。超额完成日志经验证后移入 `.retiring`，两侧目录同步后才删除宿主日志文件。清理中断可由下一进程继续处理。活动、损坏或无法辨认的日志不按时间淘汰；未完成目录超过 256 时仍阻止写入。

卷激活会迁移旧完成日志、复核当前卷的未完成记录。最终旧对象回收并完成 NTFS 清理后归档当次记录；归档失败不伪装成磁盘文件操作失败，保留记录等待下次维护。全部日志维护都只涉及 Mac 上的应用恢复目录，没有 NTFS 删除/修复回调。
