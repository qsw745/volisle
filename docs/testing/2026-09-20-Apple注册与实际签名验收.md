## 实际签名验收

产物：`apps/macos/build/signed/top.qisw.volisle.app`。

1. 先签嵌入式 FSKit 扩展，再签主应用，使用本机已有 Developer ID Application 私钥；没有生成或导出私钥。
2. `codesign --verify --deep --strict --verbose=2` 通过，结果为 valid on disk / satisfies its Designated Requirement。
3. 主应用与扩展的 TeamIdentifier、Identifier 精确匹配；两者 Hardened Runtime 均开启。
4. 从实际扩展签名提取 entitlements，四项精确匹配：沙盒、FSKit Module、扩展应用标识、团队标识。
5. 签名结果 JSON 已写入并回读，包含已签名二进制哈希与构建记录哈希。未安装、未公证、未验证加载状态均明确为 false。

包保持只读编译，不声明自动接管 NTFS 的 FSMediaTypes。通过 `statvfs` 再次确认 `/Volumes/qsw` 为只读；本轮没有读写已有文件、写入测试数据、卸载或推出该硬盘。
