# 后台只读挂载事务接入与实盘验收

本阶段把此前由验收脚本分别执行的“正常卸载、引导检查、恢复系统只读挂载”接入了已签名的应用和 root 后台组件。应用通过固定 XPC 请求提交操作，后台独立执行并保存状态；客户端退出、断连或查询超时不取消后台工作。

**真实 2 TB qsw 验收通过。** 本阶段仍是只读事务：没有开放写入适配器或主界面的写入按钮，不能称为完整读写产品。

## 实现与边界

- `HelperMountCycle.swift`：单一后台事务，操作 ID 去重、实际连接用户隔离、阶段转换和恢复。开始前核对设备及权限；先保存记录，再提交正常卸载。检查失败仍进入只读恢复，恢复未确认则阻止新事务。
- `HelperMountJournal.swift`：后台固定目录 `/private/var/db/volisle`，目录 0700、记录及进程锁 0600。目录文件描述符、拒绝符号链接、所有者/类型/硬链接检查、8192 字节上限、独占锁、原子替换和 fsync。路径不来自 XPC 输入。
- `NativeReadOnlyDisk.swift`：使用公开 Disk Arbitration 接口，保留精确 DADisk 与会话直至系统回调。正常卸载不带 force；挂载只传固定 `rdonly,nosuid,nodev`。不通过 shell，也不让客户端提供挂载路径、命令或选项。
- `SystemHelperMountCycleBackend`：再次读取实际注册表 ID、分区大小、USB 外置分区和系统挂载表。拒绝内部盘、整盘、非原生 NTFS 挂载和非只读挂载。未挂载目标不额外挂载；原来已挂载的目标恢复系统只读状态。
- `HelperMountRPC.swift` 与既有签名 XPC：固定 start/status/latest/recover 操作。用户 ID 取自实际 XPC 连接，不信任请求中的用户字段。协议不提供写入、格式化、修复、强制卸载或任意命令能力。
- `HelperServiceController.unregister()`：先在后台原子停止接收新事务，再注销系统组件；事务未结束或需要恢复时拒绝注销。单纯先查状态再注销会有并发窗口，因此增加 quiesce/resume 握手。
- `AppEntry.swift`：接入已签名应用内的固定支持命令，用于验收与后续界面协调器调用。本阶段没有把会临时卸载磁盘的操作静默塞入原来的“检查磁盘访问”菜单。

后台重启发现非终态记录时标为待恢复，不自动重复卸载或挂载。恢复必须绑定原记录；启动会话不同的旧记录不会操作当前同名设备。当前只有一个最近操作记录；去重覆盖当前记录，不是无限历史请求去重系统。

## 验证结果

### 自动与镜像验证

- **101 项核心测试、13 个测试组通过**。新增覆盖：持久记录先于卸载、检查失败后恢复且不报成功、恢复失败后阻止新操作、显式重查、重复请求、不同用户、变更设备、后台重启、跨系统启动会话、符号链接/损坏记录、无效输入、注销前停止接收事务。
- **7 项真实签名 XPC 通信检查通过**：正确身份通信、错误客户端/服务器、临时签名、调试权限等拒绝；临时测试服务已正常清理。
- 一次性 **64 MiB NTFS 镜像**上执行实际系统只读挂载、读取中文文件校验、正常卸载、读取引导区、再次恢复只读并正常卸载；随后验证原有盘屿 FSKit 只读挂载、读取及写入拒绝。全部通过，镜像正常分离，整份 SHA-256 不变。
- 第一份镜像在把原生挂载检查排在手工 FSKit 挂载/卸载之后时返回 busy；保留失败记录且镜像正常分离、摘要未变。随后调整开发验收顺序，先验证后台所用原生调用，再验证独立 FSKit 执行层。没有通过强制卸载或忽略错误解决。该 busy 的具体系统内部原因未确认，不能视作任意混合挂载顺序都已验证。
