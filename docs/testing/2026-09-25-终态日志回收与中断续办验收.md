# 终态日志回收与中断续办验收

日期：2026-09-25。

## 已完成及范围

原生可信存储新增显式日志回收入口：已持久结束的正常提交或回滚事务，可以删除对应完整块日志，释放选定日志目录的空间与文件额度，同时保留独立终态凭据。旧事务仍不能重用、继续写入或再次回滚。

32 项新专项、285 项真实 NTFS 镜像检查、289 项相关专项回归及核心包 179 项测试通过。本轮没有操作 qsw、真实块设备或此前的故障镜像；没有安装后台、替换应用或发布下载/更新。安装版仍为构建 4。

本轮只实现并验证显式回收机制，没有启用正式后台自动清理。生产检查点、真实设备保护、长期凭据容量和正式后台/FSKit 接入仍未完成，正式发布阻断保持。

## 删除授权与顺序

1. `BlockJournalAuthority.retireLog` 验证独立可信状态、密钥、完整磁盘绑定及持久终态。活动事务、仅有提交日志但尚未结束的事务、未知事务、绑定变化均拒绝。
2. 获取选定日志目录的独占锁，按事务 UUID 定位文件；不遍历删除、不按文件年龄推断、不修改磁盘数据。
3. 文件存在时，认证全部日志记录，要求精确最新凭据一致，且日志提交状态与终态种类一致。文件、目录及父路径不得通过符号链接替换，硬链接、非私有权限、损坏和截断日志均拒绝。
4. 删除前再次核对文件 inode、目录身份、路径和日志未变化，再执行 `unlinkat`。重新打开目录仅用于身份核对，不释放原独占锁。
5. 对目录执行 `fsync` 和 `F_FULLFSYNC`，再次核对路径身份及目标文件确实不存在，才返回成功。相关系统调用在当前本地隔离目录实测成功；其他文件系统若不支持则返回失败，不静默忽略。

独立结束凭据本来就必须先于回收持久化，因此无需为了回收再引入新的状态格式或删除授权日志。凭据文件和密钥不因回收而修改。

## 中断及重复请求

- 删除前中断：日志仍在，重启重新认证后回收。
- 删除后或目录持久化期间中断：返回错误不等于日志仍在。重新打开可信存储，再检查同一目录；若名称已经不存在，重新刷新目录。
- 返回 `true` 表示本次删除了文件；`false` 仅表示选定目录中该名称已不存在且目录已刷新，不声称其他目录的副本也被回收。
- 名称在刷新期间重新出现时拒绝成功，并保留新出现的文件；不继续删除。
- 若新事务已经开始，旧回收请求仍只定位旧 UUID。旧事务的终态防重放记录保留，不能撤销新事务数据。
- 异常和吞掉的重入错误都会锁住当前可信存储实例，要求重新打开核对。

## 尚未覆盖

- 回收释放的是日志目录额度。独立终态凭据仍受 256 条上限约束；满额继续拒绝新事务，不能把本轮结果称为无限期持续写入已完成。长期凭据压缩/代际防重放需要后续实现和验收。
- 当前回收解析上限为默认的 64 MiB / 4096 条日志记录；更大的非默认日志保留拒绝，不强制删除。
- 跨目录总预算、自动清理调度、生产日志目录管理、真实卷跨连接身份及设备独占保护未接通。
- 未接入正式后台/FSKit 持续挂载流程；未验证真实断电、不同文件系统的目录持久化或最终安装包。
