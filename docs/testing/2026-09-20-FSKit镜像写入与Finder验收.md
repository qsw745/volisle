# FSKit 镜像写入、Finder 与缓存一致性验收

本轮已完成一次性 NTFS 镜像上的系统写入、Finder 复制、正常卸载、独立读取与只读重挂。过程中发现并修复缓存范围重叠导致的空间重复分配问题。**当前只证明下述小镜像场景；真实磁盘写入、自动挂载及公开发行仍未开放。**

## 保护边界

- 用户 2 TB Seagate `qsw` 始终保持系统只读，本轮未在其中创建、修改或删除文件，未修复、格式化或重新挂载该盘。
- 写入只允许脚本新建的 64 MiB 普通镜像；构建与签名均核对镜像 SHA-256、容量、序列号、普通文件属性和未连接状态。扩展还要求编译时序列号匹配、设备可写及显式 `volisle-rw` 选项；只读选项优先。
- 普通构建不含实验写入宏。签名脚本默认拒绝实验包；实验包必须再次明确指定同一镜像。
- 未声明自动识别接管 NTFS 的 `FSMediaTypes`，未启用内核卸载 I/O。全部构建与测试在本机完成，无公证、上传或发布。
- 只执行正常镜像断开，未强制卸载。一次激活失败留下的未挂载实验模块在确认没有 Volisle 挂载后单独终止，随后正常断开镜像；失败样本保留。

## 实现修正

1. 系统 `loadResource` 回调没有挂载参数；改在 `activate(options:)` 核对写入意图。
2. 激活期间内核缓存尚不可用，不能执行写入引擎初始化中的标脏与同步。先打开只读引擎，首次实际修改前确认缓存可用，再切换到写入引擎；失败不降级为写入成功。
3. 关闭后的重复同步保留先前失败状态，不再将空引擎当成新的同步失败；避免在内核挂载已消失后多做一次缓存刷新。
4. 补齐最大文件长度能力。Finder 复制重设当前权限、所有者及零标志时接受无变化请求；真实权限变化仍拒绝，不能伪称已持久化。
5. 固定缓存块，详见下面的故障记录。

## 发现的真实损坏与修复依据

失败镜像：`.workbench/fskit-readonly-dv0d1twa/fixture.img`，SHA-256 为 `8ddbb20128559135e21eafec39910145e146207e0639a8d64e210f828e429b92`。这是本轮新建镜像，没有用户数据。

Finder 复制当时显示成功，但卸载后 `ntfscat` 发现另一份测试文件的哈希变化。被截断为 2,097,169 字节的 `4MiB.bin` 从偏移 131,072 开始出现事件日志内容。文件记录 68 的区段覆盖 LCN `0x3220..0x3420`，而 `.fseventsd` 文件记录 104 又使用 `0x3240`，发生重复分配。卷的 dirty 位已经清除，因此“正常卸载、dirty 位清除”不能代替文件完整性检查。

本机 Apple SDK 的 `FSResource.h` 在 `metadataRead` / `metadataWrite` 注释中明确要求：缓存按偏移寻址，不检测重叠；同一区域必须使用相同的 `(offset, length)`。原实现仅按扇区对齐，仍把不同长度的请求整体交给缓存，违反该要求。单独使用普通文件 I/O 的 C 桥接做 100 次分配删除未复现；模拟该缓存规则的回归测试在旧实现下稳定读到过期分配位图。

修复后，所有缓存读写经 `MetadataBlocks` 拆分为固定块；容量仍用逻辑块数计算。尾部不足一块时使用唯一固定尾块，非对齐请求先读取固定块再修改。回归覆盖过期位图、缓存键长度、尾块及越界拒绝。修复后的真实 FSKit 镜像测试和独立分配检查均通过；这支持本次修复有效，不等于所有损坏风险已经排除。

失败镜像保留原样，未尝试修复。此前 Finder 测试还曾在该镜像新建目录内意外粘贴一份 849,862 字节图标；仅此临时副本随后被删除。后续回归显式加入相同大小的分配、删除负载，不依赖该偶发 UI 操作。

## 修复后的验收

镜像：`.workbench/fskit-readonly-bnqy7syp`；候选：`apps/macos/build/signed-fixed-cache`。最终镜像 SHA-256：`7a44415f1fa5cfe9f08fded3aa1c0c861277b71746d7d00d82f69d29a5efc362`。

- 创建、写入、fsync、读取；中文、空格、emoji 文件名；改名、跨目录移动、删除测试文件和空目录。
- 4 MiB 写读，跨扇区局部修改并截断；32 个小文件枚举。
- 时间戳及扩展属性的设置、读取、列举和删除；无变化权限请求成功，真实变化明确拒绝。
- 覆盖改名明确拒绝且两份文件保持原内容。
- 64 轮 849,862 字节文件分配/删除，每轮另保留不同内容的 707 字节文件。
- Finder 新建中文目录，复制镜像内预置中文文件，GUI 显示及目标哈希通过。此前只读镜像上的 Finder 浏览和快速查看也已通过。
- 正常断开后用独立上游 `ntfscat` 校验全部预期文件；重新只读挂载校验哈希、时间和扩展属性，写入得到 `EROFS`；两次挂载均正常断开并清理挂载点。
- 独立扫描 126 条使用中的 MFT 记录、1,313 个被文件占用的簇，未发现区段重叠或“已占用区段被位图标为空闲”。同一检查器在旧失败样本检出 513 条问题。此检查只覆盖上述两项，不是完整 NTFS 检查或 Windows `chkdsk`。

`write-result.json` 的 16 项检查先完成，分配扫描随后单独运行；汇总见 `fskit-write-result.json`。新测试脚本已把分配检查纳入以后运行的成功条件，不能把这次分开的证据改写成同一次脚本运行。

另外，本轮核心包 41 项测试、桥接 21 组镜像检查、写入门禁 9 场景、镜像校验 7 场景、清单 15 场景及签名描述文件 11 场景通过。固定缓存块回归先观察失败，再修复通过。
