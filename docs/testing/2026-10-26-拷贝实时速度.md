# 应用内拷贝实时速度

日期：2026-10-26。范围：官网版“拷贝到这块盘…”及拖入盘屿窗口的拷贝任务。

## 实现

- 进度详情下新增“速度：X MB/s”，自动使用 B/s、KB/s、MB/s、GB/s，每半秒刷新，数字按界面语言格式化。
- 最近约 3 秒的平均传输速度，使用单调时钟；50 毫秒时间桶合并密集的小文件报告，保留窗口边界插值所需样本。
- 数据来自本次运行成功写入的字节；跳过文件、核对完整文件和续传已有部分不计入速度。计数仅用于显示，不参与恢复偏移、完成判断或刷盘顺序。
- 首次报告建立基线，后续报告开始显示速度；等待、暂停、核对阶段和完成后隐藏。续传及核对结束后重新采样，避免把历史容量或暂停时间算进速度。
- 文件系统阻塞且没有新报告时，界面仍更新，最后一次报告约 3 秒后显示 0 B/s。每个任务独立统计。
- 简体中文、繁体中文和英文文案已补齐。

## 验证

- 新增 11 项测试，覆盖历史偏移、变速窗口、边界插值、无新报告衰减、密集小文件、偏移下降、重复或迟到时间、任务状态切换及多任务隔离。
- 实际队列 worker 到主线程的速度更新、核对清空和暂停隐藏通过；临时移除队列采样调用后，两处速度断言失败，恢复后通过。
- 临时普通文件复制：3 MB 计划跳过 1 MB 时只统计实际写入的 2 MB；重跑复用完整目标文件时统计 0。没有对用户磁盘测试写入。
- 高频报告及新增写入计数都先由失败用例复现，再验证修复。
- 最终核心测试：512 项、49 组全部通过。三语本地化：742 键，0 问题。`git diff --check` 通过。
- 本机 Release 双架构编译通过，`lipo` 确认 App 可执行文件包含 arm64、x86_64。当前 SDK 对 x86_64 / macOS 27.0 组合有弃用警告；本轮没有改变支持系统声明，也没有实体 Intel 设备验收。
- 独立只读复核发现的高频窗口缩短问题已修复；对修正及实际写入计数的后续复核没有发现可操作问题。
- 使用实际 `CopyJobsSection` 和人工状态样本渲染原生界面，确认运行时显示速度、暂停和核对时隐藏。该样例不是实盘性能测量，不表示复制速度承诺。

## 追加：真实复制与动态界面验收

用户要求核实实际效果后，新增隔离验收窗口：逐字复用本次正式 `CopyJobsSection`，使用正式 `CopyQueue` 和 `ResumableCopier`，在 APFS 临时普通目录间实际复制一个 1 GiB 文件。没有构造完成状态或复制速度；为便于稳定观察，在真实复制的状态回调后人为等待 80 毫秒，并可阻塞回调模拟无新进度。该受控速度不代表硬盘性能，也不等价于 NTFS 实体盘或物理设备故障验收。原安装应用仍为 0.9.8（80），没有替换或改动其设置。

- 通过原生界面“开始实际拷贝”启动，实际看到进度与速度（截图示例 45.6 MB/s）。
- 点击正式“暂停”按钮：保留 461,373,440 字节进度，速度立即隐藏。
- 点击正式“继续”按钮：先实际比较已有片段，94 次采样记录处于核对状态，均不显示传输速度；核对完成才恢复传输速度。
- 继续运行实际新增写入 612,368,384 字节；与暂停保留的字节相加恰为 1,073,741,824 字节，没有把已有部分再次当作新流量。
- 在受控等待中，没有继续写入或新进度；界面定时更新到 `0 B/s`，采样中有 104 条等待归零记录。结束等待后恢复传输，完成后隐藏速度。
- 对 148 个稳定采样点，用目标临时文件的实际大小增长量独立比较显示速度，相对差异中位数 4.48%；界面统计与文件大小观察存在采样时差，不将两者声明为逐点相同。
- 完整源、目标均为 1,073,741,824 字节，SHA-256 同为 `bff55c8dacc2c24d85f5fc1a586593ad9659b7c45428256737106b9796e3d538`。
- 本轮重新执行 11 项速度专项测试，全部通过。正式产品源码没有新增改动；验收窗口已正常退出，测试源和目标大文件已清理。
