# 简洁界面与开源引擎开发验收

执行日期：2026-09-20。产品模式：官网免费开源，Mac App Store 收费。未公开托管、发布或上架。

## 已完成的开发

- 主窗口保留磁盘列表、名称、状态、容量、打开 Finder 和推出；详情移到“更多”，引擎与诊断移到设置。未完成的 NTFS 写入只保留一句状态提示，没有空操作按钮。
- 新增 DiskActions 状态机和 SystemDiskActions：正常卸载/推出、设备互斥、卸载失败停止、热插拔身份复核。卸载单卷与推出整设备分开，整设备操作先展示确认。无强制选项，无 shell 或 root 服务。
- 登录启动接入 SMAppService；本地无 Bundle ID 的开发包禁用，注册失败回显真实状态。此次未注册任何登录项。
- 基于固定 ntfskit 驱动源码建立 GPL C 桥接，排除修复、格式化、BitLocker 和内核卸载 I/O。新增只读风险检查、同步回调和错误传播，修复只读创建虚假成功及创建时的关闭错误被忽略。
- FSKit 开发模块独立编译，默认只读，不嵌入普通开发 App。实验可写路径需要独立编译条件与显式选项；未启用该条件、未注册扩展。对覆盖式 rename 等未验证能力返回不支持。
- 新增未签名候选打包脚本，必须提供实际拥有的 Bundle ID；本次只校验脚本语法/帮助，没有代填标识或生成发行候选。
- 原创源码添加 GPL v2 许可，复用组件保留来源、许可和修改记录；未公开源码仓库。
- 官网明确免费开源与商店收费两个渠道，简化界面原型；没有虚构下载、源码仓库、价格或购买链接。

源核心重新以显式 MACOSX_DEPLOYMENT_TARGET=15.4 构建；扩展使用 26.4 目标，以使用能够正确表达只读挂载状态的 FSKit API。声明的编译目标不等于产品支持范围。

## 未完成及下一步

1. 签名身份与能力：需要实际 Team ID、主应用 Bundle ID，核对 FSKit entitlement 与签名后的扩展加载行为。尚未申请权限、安装驱动或提交构建。
2. 实际闭环：需要指定可丢弃测试介质与 Windows 检查环境。现有 NTFS 硬盘仅被元数据枚举，未被选择作测试盘、写入或推出。
3. 引擎完整性：扩展属性、Finder 覆盖保存语义、权限属性、日志/dirty 生命周期、崩溃恢复与卸载同步语义需进一步实现/验证；桥接基础测试不能替代这些事项。当前真实写入仍关闭。
4. 产品接入：扩展可用性检测、真实写挂载、按卷自动挂载、与其他驱动冲突处理、睡眠唤醒、超时和完整错误映射仍需在真实扩展环境完成。
5. 安装与发行：macOS 多版本、Intel、磁盘满、大文件、异常退出、忙碌卷、安装卸载更新和最终包验收均未完成。商店分发许可和实际包审核独立核对。

因此：本轮是实际代码与验证增量，**完整 NTFS 产品尚未完成**，不能对外作为可写驱动发布。
