# 恢复设备会话与失联隔离验收

日期：2026-09-25。

## 实现及适用边界

新增 `BlockJournalDeviceSession`，把恢复期间的 I/O 与调用方已经持有的设备会话绑定。每次读、写、刷盘和显式核对前后，均检查卷身份、引导扇区摘要、容量、日志块大小、当前连接标识、租约标识、租约是否仍持有、是否未挂载及是否可写。任一变化、观察失败或 I/O 失败会锁住本会话，后续操作不能继续访问设备。

这是恢复 I/O 的共用保护层，**不是物理设备租约实现**。`ownsLease` 等信息必须来自已经取得设备控制权的可信传输层，不能接收 UI/XPC 的自报值。组件本身不会调用 Disk Arbitration、抢占设备、卸载磁盘或打开 `/dev`；也不能防御拥有原始设备访问权的外部进程。当前没有实现跨重启、跨 USB 连接的生产磁盘身份认证。

- 单次读最多 1 MiB，拒绝越界、负值及短读。空读仍核对会话，但不调用底层读取。
- 每次写入只接受一个对齐的完整日志块；卷末不足一个日志块时，必须精确等于设备剩余长度，与日志存储及回滚器的规则一致。
- 失败通知只发出一次。发生错误后保持底层资源，由恢复调用方在日志/凭据处理退出后释放；不自行重试部分写入，也不清除 dirty。
- 同步回调重入即使吞掉错误，外层也不得返回成功；回调过程中关闭会话，会等本次回调退出后再释放资源。
- 类型不提供并发执行能力，须由单一执行上下文串行使用；没有使用 `Sendable` 绕过这个约束。

测试专用 `DetachedRecoveryDevice` 只接受 `.workbench/block-journal-*` 下 64 MiB 普通文件，复制并持有已锁定的文件描述符，逐次核对文件/父目录身份、路径、文件大小、所有者、链接数、引导扇区及合作式文件锁。它不在正式后台使用，普通文件的 `flock` 不等于 macOS 物理磁盘独占访问。

真实 NTFS 隔离驱动已将此会话接入原生回滚、正常提交完成核验，以及中断完成记录的续办核验。设备会话保持到本次凭据处理结束。原有认证日志、独立基线和挂载安全预检仍是必须满足的条件，设备身份核对不能替代它们。

## 验证

43 个会话边界场景通过，包含在核心包的 193 项测试（22 组）中，不能重复累计。10 个普通文件系统故障场景通过，包括释放文件锁、路径替换、符号链接、硬链接、文件大小改变、引导扇区改变、父目录替换、读取中替换，以及部分写入后抛错。

真实 NTFS 最终矩阵 **372 项通过**，包含原有 366 项回归，以及本轮新增 6 项设备会话故障/续办检查：释放锁、替换路径、关闭传输层各自均在恢复中被拒绝，镜像和日志/可信凭据字节保持不变；在重新取得有效会话后，各自恢复成功，完整镜像摘要及独立 NTFS 文件回读一致。

真实引擎报告：`.workbench/block-journal-j7hq01tk/result.json`。普通文件故障报告：`.workbench/block-journal-device-a6962ef4-900a-44e1-9822-68a5f9266186/result.json`。最终源码对应 `engine-final.log`；`engine.log` 是较早接入版本的 366 项回归，不用它冒充最终源码验收。完整状态和源码/测试程序摘要分别保存在 `handoff.json`、`source-hashes.json`。

测试先记录缺少实现的失败；随后补充卷末边界，复现 `.invalid` 拒绝合法尾块，再调整为精确剩余长度，相关回归通过。证据目录：`.workbench/device-fence-20260925/`，保留 `red.log`、`tail-red.log`、`core-final.log` 和 `detached-final.log`。

## 复现

```sh
swift test --package-path packages/VolisleCore
python3 scripts/test-block-transaction-engine.py
swiftc -swift-version 6 \
  packages/VolisleCore/Sources/VolisleCore/BlockJournalStore.swift \
  packages/VolisleCore/Sources/VolisleCore/BlockJournalDeviceSession.swift \
  scripts/fixtures/detached_recovery_device.swift \
  scripts/test-detached-recovery-device.swift \
  -o .workbench/device-fence-20260925/detached-tests
.workbench/device-fence-20260925/detached-tests
```

所有编译及测试均在本机。只操作本轮新建普通测试文件；失败保留证据，成功只清理对应测试创建的文件。没有操作 qsw、旧损坏镜像或系统权限，没有替换已安装应用，也没有开放下载或更新项。

## 未完成

实际设备的稳定身份、Disk Arbitration 占用控制与生命周期、内核/文件系统资源移交尚未实现或验收。生产恢复检查点、正式后台恢复协议及 FSKit 持续挂载日志接入仍未完成。当前安装版不会取得本轮源码中的恢复保护；发布门禁维持阻断。
