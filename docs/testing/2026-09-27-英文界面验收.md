# 英文界面验收（0.3.3 构建 19 候选）

日期：2026-09-27。

## 做法

- 以中文原文为键。应用层直接写在 `Text`/`Button`/`Label` 等处的字面量由 SwiftUI 自动查表；先算成 `String` 再显示的文案（侧栏状态、首次设置提示、更新状态、错误与状态说明、诊断报告）改为 `String(localized:)`。
- 翻译表放在 `assets/brand/Localization/app/{en,zh-Hans,zh-Hant}.lproj/Localizable.strings`，由 `scripts/build-macos.sh` 复制进应用包。
- 中文两份表必须存在且为“原文 = 原文”：开发区域为 en，实测缺少中文表时，简体、繁体、香港中文系统都会退回英文表。
- `scripts/check-localization.py` 用编译器的 `-emit-localized-strings` 收集全部键（本次 285 个），检查三份表覆盖、英文占位符一致、中文表为原文、无多余键，以及应用界面源码中没有会原样显示的中文字面量。反向测试（删一条英文、加一句未本地化中文）两项均被发现。

## 结果

- 按语言：zh-Hans、zh-Hant、zh-HK 显示中文；en、ja、fr 显示英文（最小测试应用实测）。
- 本机构建 19（`-AppleLanguages (en)` 启动）：主窗口、状态栏提示、按钮与系统菜单均为英文，无截断（`screenshots/2026-09-27-0.3.3-英文界面主窗口.png`）；正常启动为中文，与之前一致（`screenshots/2026-09-27-0.3.3-中文界面主窗口.png`）。
- 核心测试 246 项通过；测试进程中 `String(localized:)` 返回原文，原有中文断言不受影响。

## 未覆盖或未翻译

- 设置窗口、菜单栏菜单、确认对话框、恢复窗口未逐一截图（键已全部覆盖）。
- 读写扩展与后台组件的日志、恢复记录的内部校验原因、恢复导出的文件与文件夹名、仅用于测试镜像的文案仍为中文。
- 官网、帮助页与发布说明仍为中文；Sparkle 更新窗口由 Sparkle 自身按系统语言显示。
