# 即插即用自动读写

## 用户确认的产品体验

首次打开完成扩展、后台组件与完全磁盘访问设置后，软件运行期间插入支持的 NTFS 外接硬盘或 U 盘，自动检查并挂载读写，正常使用只需 Finder。关闭主窗口继续工作；完全退出后停止处理新连接。登录启动保留系统原生开关，未经用户选择不擅自修改系统登录项。自动模式可在设置暂停，手动按钮保留为备用入口。

## 实现

- 全局 v2 自动读写偏好取代普通用户逐盘开关。日常构建默认开启，显式暂停可持久化；损坏或未知版本偏好不启用自动写入。普通只读与实验构建不会因默认值获得日常读写能力。
- qsw 一类无持久 UUID 的磁盘在全局模式下可由可信后台核对当前 IORegistry 连接；不存储或猜测永久授权身份。不更改后台的物理 USB / NTFS / 外接非系统盘限制，预检失败仍拒绝写入。
- 前置能力缺失不消耗本次连接的尝试次数，设置完成后可重新检查；真正的挂载失败每次连接仅尝试一次，避免反复卸载。队列在后台空闲后处理下一卷，不抢占已经存在的事务。
- 磁盘及后台状态监听归属于 App 生命周期的 BackgroundDiskRuntime，不依赖主窗口是否显示。唤醒或返回 App 时重新检查权限/后台状态；恢复失败不会因观察回调形成无限重试。
- 暂停自动模式不会强制中断进行中的后台事务或卸载已读写卷；手动恢复只读后不会在同一次连接中立即重新打开。
