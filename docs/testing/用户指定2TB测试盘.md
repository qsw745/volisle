# 用户指定的 2 TB 测试盘

2026-09-20 用户授权：这块 Windows 使用的外接盘可用于新增测试数据和读写测试，尽量保证已有数据，不操作已有文件。授权针对该盘及新增测试文件，不是任意磁盘、格式化、修复、分区调整或故障破坏实验的授权。

## 已核对

截图为 Seagate Expansion Media，卷名 qsw，USB 外接、MBR 分区表、NTFS，容量约 2 TB。本轮通过 diskutil 只读查询核对：当前为 disk6 / disk6s1，挂载于 /Volumes/qsw，文件系统 ntfs，整盘 2,000,398,933,504 字节。BSD 编号和挂载路径仅用于本次观察，重连后必须重新发现，不能作为授权身份。

卷 UUID、设备关系等实时信息已读取。diskutil 未返回该 MBR 分区的 DiskUUID；当前要求媒体 UUID 的稳定身份策略需核查 Disk Arbitration 实际字段并设计 MBR 支持，不能为这块盘简单移除身份校验。

后续实现与核验：Disk Arbitration 同样没有返回媒体 UUID，但 IOKit 可读取该 USB 设备序列号、厂商/产品编号与分区 Base/Size。已增加这些字段的 SHA-256 组合身份与当前 IOMedia 注册实例校验。原始序列号不保存、不打印。实盘只读探针已返回“稳定身份 true、MBR 摘要身份 true、本次身份复核 true”；换接口、重插场景目前仅用单元测试覆盖，未实际拔插这块盘。详情见《2026-09-20-MBR身份与自动挂载基础验收》。

本轮没有扫描既有文件内容、没有写入测试文件、没有卸载或改变挂载状态、没有加载实验驱动。
