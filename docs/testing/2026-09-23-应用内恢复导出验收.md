# 应用内恢复导出验收

日期：2026-09-23。范围：0.2.0 本地日常候选；不是公开正式版。

## 本次实现

- 主界面保留简洁布局，新增“更多 → 恢复文件…”；可读取扩展的未完成记录或只读打开用户选择的备份记录。
- 主应用和扩展共用 `VolisleCore/ReplacementJournal.swift`，没有另写宽松的恢复日志解析。默认、日常和实验构建均在只读打开引擎后审计未完成记录；切换构建模式不再跳过审计。
- 真实介质先正常卸载，可信后台新读引导哈希；以原生只读方式挂载后导出。每块复制核对 VFS 只读标志、来源设备与挂载点，结束时复核实时介质连接/容量和挂载身份。macOS 不允许已挂载设备再次 raw open，故结束检查不尝试第二次原始设备打开。
- 仅导出长度和 SHA-256 与记录一致的旧/新内容，输出回读校验后再发布。新目录独占创建，不覆盖现有输出；取消、源变化、错误会删除本次尚未发布的临时输出，保留用户已有内容。
- 源路径逐级 `openat`，拒绝符号链接、特殊文件和跨文件系统内容。目标禁止位于源卷内，使用私有目录和文件权限。
- 报告区分完整/部分导出，包含各版本的校验信息。保留源文件与原日志，不自动修复、清理、恢复写入或删除备份。

## 证据边界

真实盘验证使用**模拟中断记录 + 真实只读测试文件**，没有制造物理盘中断或执行磁盘修复。模拟记录的 MFT 引用及卷序列字段不是物理故障现场证据；导出流程证明实际引导哈希、当前设备连接和数据内容，不能据此证明完整 MFT 身份或授权删除。只恢复未命名数据流，未恢复 ACL、扩展属性和时间戳。

同名覆盖日常开放、私有 POSIX 权限、实际应用保存兼容、Windows 交叉检查、实体热拔插/断电和多系统支持仍未完成。没有将这些未覆盖项视为通过。当前候选未公证、未公开发布，完全磁盘访问保持用户已有设置。
