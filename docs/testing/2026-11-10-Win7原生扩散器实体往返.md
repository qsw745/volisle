# Windows 7 原生 AES-128 扩散器：实体盘双向验收

2026-11-10，盘屿 0.9.11 兼容测试版 4（构建 92）。本轮未修改产品代码，也未发布新版本或更改正式更新渠道。

## 结论与范围

用户在 Windows 7 中原生加密的 USB 分区“加密测试”已通过：密码解锁、48 位恢复密钥解锁、原有测试数据哈希校验、Mac 新增/追加/改名/删除、同步回读、正常锁定与重新解锁、Mac→Win7 和 Win7→Mac 的文件内容核验。

Windows 独立报告确认系统为 `Microsoft Windows 7 旗舰版`、版本 `6.1.7601`，加密方法 `1`，加密比例 100%；执行的校验器同时要求转换状态为 FullyEncrypted。依照 [Microsoft GetEncryptionMethod](https://learn.microsoft.com/en-us/windows/win32/secprov/getencryptionmethod-win32-encryptablevolume)，方法 1 为 AES-128 + 扩散器，即本次测试的 AES-128-CBC + Elephant Diffuser。

**本结论仅覆盖已验证的 128 位路径。** 原生 256 位样本、专用只读挂载与中断恢复压力场景未在本轮验证。旧的 Windows 11 转换镜像互操作失败仍保留为独立历史记录，不用它替代本次 Win7 原生实盘结果。

后续补验：原生 256 位已在正式候选 93 上完成，见 [256 位实体往返](2026-11-10-Win7原生256位扩散器实体往返.md)。上面的范围说明保留首轮 128 位验收边界。

## 设备与流程

- USB 希捷 2 TB 盘上的约 1.07 GB 独立分区；分区 UUID `44D4CEE8-FF63-4037-BE1A-8934977EE163`，原始大小 1,072,693,248 字节。本轮连接为 `disk4s3`，每个阶段均重新核对分区身份，未格式化或重分区。
- 用户在本机盘屿手动输入密码，没有向聊天或验收记录提供凭据。应用显示内部 NTFS 卷名“加密测试”，解锁后可读写。
- 首次读取 `Volisle-BitLocker-Test/manifest.json` 的 15 个测试文件，大小及 SHA-256 全部匹配，覆盖中文、多语言、图片、嵌套目录、空文件、1 字节、4095/4096/4097 字节边界及 16 MiB + 123 字节文件。另保留原 manifest 和 SHA256SUMS，两份清单没有改动。
- 新建独立目录 `Volisle-Win7-Mac-20261110-4dcb0f1b`，保存中文文本、2 MiB + 1 字节二进制、带空格及中文子目录内的图片副本、空文件，共 4 个持久测试文件；完成追加、改名及仅删除本轮自建临时文件。写入后执行 fsync 并回读，15 个原始文件仍与原清单相同。
- 正常锁定并由用户再次解锁，新挂载会话中的 21 项（15 个原始文件 + 2 份原清单 + 4 个 Mac 文件）全部相同。
- 提供可审阅的 Windows 7 校验器：不使用新版本 PowerShell 专有命令，不修改执行策略、保护器或原始文件。先核验 Windows 7、NTFS 卷名与容量、扩散器方法及完全加密状态，再核验 21 项文件，只在本轮目录新增 Windows 测试文件及 XML 报告。
- 正常锁定加密分区、恢复同盘普通 NTFS 分区只读，并在应用中安全推出整块设备。用户将硬盘交给 Win7，运行校验器后报告 PASS，再正常移除并接回 Mac。
- 回到 Mac 后读取 `windows-result.xml`，其平台、算法、卷名、分区 UUID、21 项校验数和成功状态全部符合；校验器及审阅源码哈希未变。
- 再次在 Mac 核对原有 21 项，全部相同；Windows 新写入的两个文件与 Windows 报告的大小、SHA-256 完全一致，完成双向验证。
