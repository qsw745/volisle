# FSKit 扩展开发模块

来源：NTFSItem.swift 与 NTFSVolume.swift 基于 whereteam/ntfskit 提交 b7153a8dd51b895d0a87345c6ad8e95bda963ed3 的 NTFSModule，按其根 LICENSE 的 GPL v2 声明复用。原作者版权归其权利人；完整许可证见 ../../LICENSE。未使用上游专有宿主 UI、签名团队、品牌或预编译工具。

盘屿 2026-09-20 修改：
- 删除 BitLocker、格式化、修复、卷改名及内核卸载 I/O 接口，保持首轮接入范围可验证。
- 默认只读；实验写入需要构建宏、显式 volisle-rw 选项、设备可写、64 MiB 容量及编译绑定的镜像序列号。标准构建不设置该宏；只有明确传入经校验的新建镜像目录才启用。
- 使用已测试的回调桥接及其风险预检，不恢复日志，不清已有 dirty；正常结束只清本会话标记；写挂载失败不静默改为成功。
- FSKit 单次操作整体互斥，包括命名空间状态，避免只锁 C 调用而暴露路径修改窗口。
- 默认拒绝覆盖式 rename、符号链接创建、不支持的属性变更；日志路径为 private。
- 修正块尺寸与容量边界，提供同步回调并传递同步错误。关闭失败状态保留到后续生命周期回调，不能被第二次关闭覆盖为成功。
- 接入命名流扩展属性接口，保留 EEXIST / ENOATTR / ENOSPC / I/O 错误的区分；大小查询与读取、存在策略与修改均在同一次互斥中执行。
- 文件写入将底层 POSIX 错误传回 FSKit，包括空间不足。
- 挂载意图在 activate 读取；首次修改前确认内核缓存可用，再从只读引擎切换到写入引擎。
- 缓存读写按固定块切分，遵守 FSKit 同一区域固定 (offset, length) 的约束；回归覆盖过期分配位图及实际镜像簇重叠问题。
- Finder 重设当前合成权限、所有者和零标志时允许无变化操作；真实变化仍拒绝。补齐最大文件长度能力。
- 设置和创建属性先统一预校验，再逐项更新 consumedAttributes；只回报实际完成的字段。混合请求中的不支持属性在截断前拒绝；创建属性失败仅尝试清理本次新建节点，I/O 故障导致清理失败时保留失败会话。
- 访问、修改、创建时间保留 NTFS 100 ns 精度，支持 1970 年以前的合法日期；溢出和非法纳秒值在写入前拒绝。显式声明不支持设置持久 POSIX 权限。
- 桥接普通改名增加冲突与 inode 祖先链预检、关闭错误传播和新链接/旧名称删除之间的同步点；失败不删除可能是最后入口的新名称。系统测试覆盖打开文件改名、父目录移动和删除后的描述符继续读写。普通构建仍拒绝覆盖替换。
- 文件对象持有不可变的 MFT 记录号与序列号；数据读写、属性读取按引用访问，其余路径操作先检查当前名称仍属于该对象。路径重新绑定到其他记录时分配新对象和标识；旧对象延迟回收不清掉新对象，目录移动同时迁移仅枚举过的标识。普通构建仍不开放覆盖保存或自动删除恢复副本。
- 新增原创原生恢复记录组件：私有宿主目录中追加校验链、先记录意图后修改、写后同步并记录新内容指纹、当前会话回收通知与两次身份/指纹核验后清理。重放只读，不恢复清理授权；记录失败可终止 NTFS 写会话。后续以单独的 VOLISLE_EXPERIMENTAL_REPLACEMENT 开关接入 FSKit 替换、写后记录及最终回收回调；仅限指定 64 MiB 镜像、macOS 27.0 的 tryReclaim、同目录且各不超过 8 MiB 的普通文件。沙盒私有目录持久化，重挂新进程只读复核；未解决事务保持脏卷。普通构建宏关闭。

构建：在根目录运行 ./scripts/build-fskit-extension.sh。产物仅在 .workbench/fskit-build/VolisleFS，不注册到系统，不嵌入普通开发 App，不访问设备。当前编译目标为 Apple Silicon / macOS 26.4，以正确表达 FSKit 只读挂载选项；这是实验目标，不是已验证的产品支持范围。

Developer ID 测试包已完成系统加载、隔离镜像读写、Finder 中文复制、扩展属性基础检查、独立哈希和分配检查、只读重挂。测试发现并修复过一次缓存范围重叠引起的数据损坏，失败镜像保留。记录见 ../../docs/testing/2026-09-20-FSKit镜像写入与Finder验收.md。

仍未完成：真实磁盘 flush 语义、完整 Finder 扩展属性兼容性、生产级替换保存、持久权限与完整创建属性矩阵、Windows 检查、自动挂载及异常恢复。隔离测试通过不能表述为成品 NTFS 驱动。
