## 使用规则

主标志保持宽高比 760:460，不拉伸、不旋转、不增加描边；四周至少保留标志宽度的 1/8 空白。浅色界面使用 `#1769E0`，深色背景使用反白。中文和英文名称由界面原生字体排版，避免直接使用生成稿中的文字像素。应用图标独立使用符号，不叠加 NTFS 或产品名称。

常规品牌显示建议宽度至少 24 px；16 px 用于浏览器标签等有限空间，仍能辨认整体轮廓，小岛细节较弱。菜单栏固定 28 × 17 pt，并提供 1×/2× 黑色透明模板，由系统适配明暗外观。

## 重新生成

先安装已锁定的官网依赖，然后在项目根目录运行：

```sh
node scripts/build-brand.mjs
```

脚本使用官网现有 Next.js 依赖中的 Sharp 编译矢量，不调用图像生成服务。macOS 上同时通过系统 `iconutil` 生成 ICNS。修改 `geometry.json` 后统一重新生成，不直接修改各消费端的轮廓。

生成资源已经纳入源码；常规 macOS 构建直接复制 ICNS，不要求安装前端依赖。官网构建和客户端构建仍然独立。品牌资源变更后分别执行官网构建及 `scripts/build-macos.sh` 更新本地产物。
