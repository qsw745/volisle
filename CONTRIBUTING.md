# 参与 · Contributing

欢迎通过 [issue](../../issues/new/choose) 报告问题、提出建议。目前**暂不接受 Pull Request**：盘屿直接读写用户的磁盘，每次改动都要在镜像中断矩阵和真实硬盘上验证，暂时只由维护者提交代码。发现了问题和改法，欢迎在 issue 里写出来。

本仓库按版本同步：每发布一个版本推送一次源码快照。代码按 GNU GPL v2 授权（见 [LICENSE](LICENSE)）。

---

Bug reports and suggestions are welcome as [issues](../../issues/new/choose). **Pull requests aren't accepted for now**: Volisle writes directly to users' disks, and every change is verified against an interruption matrix and real drives, so for the time being only the maintainer commits code. If you've found a problem and a fix, please describe both in an issue.

This repository is updated once per release with a snapshot of the source. The code is licensed under the GNU GPL v2 ([LICENSE](LICENSE)).
